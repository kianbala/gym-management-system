🏋️‍♂️ سامانه مدیریت هوشمند باشگاه و پیش‌بینی ریزش اعضا
یک نرم‌افزار کاربردی جهت مدیریت ثبت‌نام، تمدید اشتراک، کنترل تردد و تحلیل هوشمند داده‌های باشگاه با استفاده از Python، Streamlit و SQL Server.

🌟 ویژگی‌های کلیدی پروژه
📋 مدیریت اعضا: ثبت‌نام با بررسی اعتبار کد ملی و شماره تماس، جستجوی پیشرفته و مدیریت وضعیت اشتراک‌ها.

💳 مدیریت بسته‌ها و اشتراک‌ها: تعریف بسته‌های مختلف ورزشی و امکان تمدید یا تخصیص بسته جدید.

🚪 کنترل تردد (Check-in): ثبت ورود ورزشکاران و کسر خودکار جلسات از اشتراک فعال.

🤖 ماژول تحلیل و هوش مصنوعی:

تحلیل ساعات شلوغی: استخراج و نمایش نموداری پراکندگی ورود ورزشکاران در ۲۴ ساعت شبانه‌روز.

پیش‌بینی ریسک ریزش (Churn Risk): محاسبه امتیاز عددی ریسک عدم بازگشت اعضا (۰ تا ۱۰۰) بر اساس غیبت و جلسات باقی‌مانده.

📊 گزارش‌گیری ساختاریافته: استفاده از Viewهای تحلیلی دیتابیس برای گزارش‌گیری سریع.

🛠️ ابزارهای مدیریتی: پاکسازی و مدیریت اشتراک‌های منقضی‌شده و قابلیت ریست کامل دیتابیس با تایید چندمرحله‌ای.

🛠️ تکنولوژی‌های استفاده‌شده
Language: Python

Frontend / UI: Streamlit

Database: Microsoft SQL Server

Libraries: Pandas, PyODBC, NumPy

🚀 راهنمای نصب و اجرای پروژه
۱. پیش‌نیازها
ابتدا پایتون و SQL Server را روی سیستم خود نصب کنید. سپس اسکریپت ساخت جداول دیتابیس (create_table.sql) را در SQL Server اجرا کنید تا پایگاه داده GymManagementDB ساخته شود.

۲. نصب کتابخانه‌ها
دستور زیر را در ترمینال اجرا کنید تا تمامی وابستگی‌ها نصب شوند:

pip install -r requirements.txt

۳. تنظیمات اتصال دیتابیس
در فایل db_manager.py متغیرهای مربوط به اتصال را مطابق مشخصات سرور خود مقداردهی کنید:

SERVER_NAME = r'YOUR_SERVER_NAME'

DATABASE_NAME = 'GymManagementDB'

USERNAME = 'YOUR_SQL_USERNAME'

PASSWORD = 'YOUR_SQL_PASSWORD'


۴. تولید داده‌های نمونه (اختیاری)
برای پر کردن دیتابیس با داده‌های واقعی جهت تست ماژول هوش مصنوعی دستور زیر را در ترمینال اجرا کنید:

python generate_dummy_data.py

۵. اجرای برنامه
با دستور زیر در ترمینال برنامه Streamlit را اجرا کنید:

streamlit run app.py
